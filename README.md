**个人整合的 ComfyUI 自定义节点插件 —— 「Luy-」系列**

*AI 大模型 · 音乐生成 · 视频生成 · 镜头控制 · 图片处理 · 提示词工程 · 100+ 节点*

---

**CJ-Nodes** 是一套覆盖完整创作链路的 ComfyUI 节点包：从**本地大模型反推提示词**，到**词表驱动的提示词工程**，再到**音乐生成/扒谱、视频生成、镜头光照姿态控制、图片画布编辑**，最后到**显存管理与插件管理**，全部以 `Luy-` 前缀统一命名，开箱即用。

> ⚠️ AI 大模型类节点依赖 **llama-cpp-python**（必装），下载对应 Python 版本的预编译包：
> <https://github.com/JamePeng/llama-cpp-python/releases>

## ✨ 亮点节点

### 🎤 音乐工作流：听歌 → 扒谱 → 翻唱级再生成

**任意音频 → 完整乐谱 → 重新生成演唱版音乐**，全流程本地推理，8GB 显存可跑。

| 节点 | 能力 |
|---|---|
| **Luy-SheetSage2扒谱** | 音频 → 旋律谱/完整谱（ABC）、MIDI、调性、BPM、和弦、曲式结构、风格底稿，**一次输出 9 路**；长曲自动分窗滚动推理，转写完自动让出显存 |
| **Luy-YuE2音乐生成** | 风格 + 歌词（可外接 ABC 乐谱锁旋律）→ **48kHz 立体声**；full / melody / off 三种生成模式 |
| **Luy-音乐风格标签** | 15 类 370+ 标签点选拼 style：界面全中文，输出纯英文，按类别固定顺序、结果可复现 |
| **Luy-风格标签替换** | 把扒谱风格串拆成一行一个标签，前端面板逐项替换（调性/速度/和声/曲式…17 类），实时预览拼回 |

### 🎯 Luy-LocateAnything 目标检测 —— 一句话框出画面里的一切

基于 LocateAnything-3B 的视觉定位：输入 `person, car` 这类逗号分隔目标，输出**带框图像 + bbox JSON**。5 种任务（detect / 单目标 / 多目标 / 文字 / 关键点），配套**裁剪提取节点**按框批量裁切、边缘去背景色、羽化 —— 检测 → 素材提取一步到位。

### 🦙 Luy-AI反推 Lite —— 单节点本地视觉反推

llama.cpp 驱动的轻量 VLM 节点：**一个节点完成模型加载 + 图片反推**，GGUF 模型跑在 `models/LLM/`。

- ngram **投机解码**加速；思考模式开关（采样器级预算，任意模型可关思考）
- `分隔符` 一填，输出直接变字符串数组驱动批量下游
- 全中文界面，采样参数全暴露，支持显存限额

### 🎬 Painter 视频系列 —— Wan2.2 运动增强全家桶

| 节点 | 能力 |
|---|---|
| **Luy-Painter首尾帧** | 「逆结构排斥」算法增强首尾帧运动幅度（1.0 原速 ~ 2.0 高速） |
| **Luy-PainterI2V图片转视频（高级版）** | 双采样器工作流 + 色彩偏移修复；基础版专治 4 步 LoRA 慢动作 |
| **Luy-Painter长视频增强** | 分段链接 + 首尾帧锚定，突破单段时长限制无限续接 |
| **PainterAI2V / PainterAV2V** | InfiniteTalk 音频驱动说话视频（单人/双人、口型同步、视频重渲染） |

### 🎨 Luy-图片绘画 / 编辑 / 设计 —— 画布即节点

三个节点均内嵌**浏览器画布面板**：手绘草图、区域涂抹、排版设计直接在节点里完成。画布内容自动落盘 `input/cj_canvas/`（工作流只存引用，不膨胀草稿存储）；绘画节点还能输出**颜色区域语义提示词**反哺生成。

### 🌈 Luy-Krea2风格语义条件（改进版）

参考图通过 Krea2/Qwen3-VL 的**图像 token 路径**注入条件：多图独立编码实现多风格融合、轻微/平衡/强烈三档语义强度、宽高比保持 + 视觉分辨率可调 —— **只学风格，不抄主体**。

### 🧩 Luy-插件管理 —— 不动文件夹的插件开关

顶栏一键打开：列出 `custom_nodes` 全部插件，**点卡片即启用/关闭**（`.disabled` 后缀机制），支持整体重载；配合「重载插件」按钮，**改代码不重启 ComfyUI**。

<a id="ai-大模型本地推理"></a>

## 🤖 AI 大模型（本地推理）

全部基于 **llama.cpp**，GGUF 模型放 `models/LLM/`，节点界面已全中文化。

### 轻量即用型

| 节点 | 说明 |
|---|---|
| **Luy-AI反推Lite** | ⭐ 一节点搞定 VLM 反推：模型 + 视觉模块下拉即用，投机解码、思考模式开关、分隔符拆数组、显存限额。输出 `输出 / 输出列表 / 状态ID / 系统提示词 / 用户提示词 / 分隔结果` |
| **Luy-LlamaCpp反推(简化版)** | Lite 的全参版：温度 / TopK / TopP / 各类惩罚 / Mirostat 全暴露，`图片最小/最大token` 为加载期参数 |
| **Luy-Qwen3-VL图片反推** | 图片 / 视频帧分析，预设提示词模板 + 自定义/系统提示词 |
| **Luy-Qwen3语言大模型** | 纯文本 LLM 推理，最简参数 |
| **Luy-AI多功能语言大模型** | 从 `T/` 目录选功能模板（视频提示词、JSON 提示词、翻译…20+ 预设） |
| **Luy-LlamaCpp本地API** | 连接外部 llama.cpp HTTP 服务（OpenAI 兼容），支持图片输入 |
| **Luy-刷新提示词模板** | 重载 API 节点的预设提示词列表 |

### 进阶组合型（llama.cpp 三件套）

把「模型加载 → 采样参数 → 推理」拆成三个节点，模型与参数可分别复用：

```
llama_cpp_model_loader（模型对象）──┐
llama_cpp_parameters（采样参数）───┼──► llama_cpp_instruct_adv ──► 输出 / 输出列表 / 状态ID
图片（可选）───────────────────────┘
```

- **llama_cpp_model_loader**：上下文长度、显存限制、图片 token 范围、投机解码（ngram-map）、MTP 多 Token 预测
- **llama_cpp_instruct_adv**：one by one / images / video 三种推理模式、思考模式（`off` 对任意模型生效）、状态保存与清理
- **Luy-llama_run**：以上全部合一的单节点完整版

### 工具节点（`llama-cpp-vlm` 分类）

`bbox_to_mask`、`bbox_to_segs`、`bboxes_to_bbox`、`json_to_bbox`、`parse_json_node`、`remove_code_block`、`PromptEnhancerPreset`、`llama_cpp_clean_states`（清理状态）、`llama_cpp_unload_model`（卸载模型）—— 配合检测/反推链路使用。

> 📖 llama-cpp 域版本兼容与调试备忘见 `service/llama-cpp/AGENTS.md`。

<a id="音乐工作台"></a>

## 🎵 音乐工作台

本地音乐生成 + 扒谱双引擎（YuE2 NF4 量化），模型放 `models/YuE2/`。

### 生成线：风格 + 歌词 → 歌曲

| 节点 | 说明 |
|---|---|
| **Luy-YuE2音乐模型加载** | 加载 YuE2（NF4），VAE 自动从 `models/YuE2/vae/` 读取，进程内缓存复用 |
| **Luy-YuE2音乐生成** | 风格 + 歌词 → ABC 乐谱 → 语义 token → 流匹配 → **48kHz 立体声**；外接 ABC 乐谱可锁旋律复刻；CFG 强度、seed、高级采样 JSON 均可调 |
| **Luy-YuE2卸载模型** | 释放显存（与生成节点分工作流运行） |

### 扒谱线：任意音频 → 乐谱与信息

| 节点 | 说明 |
|---|---|
| **Luy-SheetSage2扒谱** | 输出 9 路：旋律谱ABC、完整谱ABC、风格底稿、调性、速度BPM、和弦、曲式结构、产物目录、扒谱信息；长曲自动分 300s 窗，bf16 加速，转写完自动释放显存 |
| **Luy-SheetSage2卸载模型** | 手动释放显存（约 2.7GB） |

### 风格辅助

| 节点 | 说明 |
|---|---|
| **Luy-音乐风格标签** | 15 个分类下拉共 370+ 标签（语种/流派/人声/乐器/情绪/节奏/年代），`风格 / 人声 / 乐器 / 情绪 / 其他 / 补充 / 速度` 7 路输出支持分组替换实验 |
| **Luy-风格标签替换** | 前端面板把风格串拆行，逐行「类别下拉 + 取值 + 手输 + 常用点选」替换后拼回，底部实时预览 |

> 词表在 `service/music/style_tags/*.txt`：一行一条 `中文 | English`，**加文件即加分类**，文件名中文部分就是界面控件名。


<a id="安装"></a>

## 📦 安装

1. 将 `CJ-Nodes` 文件夹放入 ComfyUI 的 `custom_nodes/` 目录
2. 安装 [llama-cpp-python](https://github.com/JamePeng/llama-cpp-python/releases)（按 Python 版本选预编译包，已验证 0.3.49）—— AI 大模型类节点必需
3. 重启 ComfyUI，节点菜单搜索 `Luy-` 即可找到全部节点
4. 按需准备模型：

| 模型 | 目录 |
|---|---|
| GGUF 语言 / 视觉模型 | `models/LLM/` |
| YuE2 音乐生成 / SheetSage2 扒谱 | `models/YuE2/` |
| LocateAnything-3B | `models/LocateAnything-3B/` |

<a id="注意事项"></a>

## ⚠️ 注意事项

- **提示词词表**：`service/prompttools/prompt_options/` 等目录的 txt 文件即词表，加文件 = 加下拉分类，改完刷新页面生效
- **音乐词表**：`service/music/style_tags/` 同理，文件名中文部分就是界面控件名
- **显存建议**：LocateAnything 8GB 卡输入最长边 ≤640；SheetSage2 默认转写完自动释放显存；YuE2 与 SheetSage2 已做互斥卸载避免 OOM
- **改代码热重载**：`service/` 下的改动用顶栏「重载插件」+ F5；改 `__init__.py` / `nodes.py` / `plugin_manager.py` 需重启
- **视频生成节点**（Painter 系列）需配合 Wan2.2 / InfiniteTalk / Flux2 模型使用
- 节点加载失败只打印日志不中断，节点「消失」先看 ComfyUI 启动日志中的 `❌ 加载文件` 输出
